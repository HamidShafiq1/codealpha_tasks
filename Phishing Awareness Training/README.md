# Phishing Awareness Training Module

A sleek, interactive, and responsive cybersecurity training interface designed for a phishing awareness internship task. This project uses a cyberpunk-inspired UI to educate users on identifying and preventing phishing attacks.

## 🛡️ Project Overview
This module serves as an interactive educational tool covering the fundamentals of phishing. It features a progress-tracked, multi-module learning experience culminating in a knowledge check quiz.

### Key Features
* **Progressive Learning:** 5 distinct modules covering definitions, email anatomy, social engineering, and prevention.
* **Interactive Email Simulation:** Hoverable hotspots that explain common phishing red flags in a sample email.
* **Knowledge Check Quiz:** A 4-question interactive assessment with real-time feedback and final scoring.
* **Cyberpunk UI/UX:** High-fidelity interface using CSS animations, grid backgrounds, and a custom color palette (Rajdhani & Share Tech Mono fonts).
* **Responsive Design:** Fully functional across desktop and mobile browsers.

## 📂 Modules
1.  **What is Phishing?** - Definitions and global statistics.
2.  **Recognizing Emails** - Visual breakdown of spoofed domains and urgency tactics.
3.  **Social Engineering** - Deep dive into psychological triggers (Authority, Scarcity, Fear).
4.  **Knowledge Check** - Interactive quiz to validate learning.
5.  **Summary** - Key takeaways and completion status.

## 🚀 Usage
1.  Clone the repository.
2.  Open `phishing_awareness.html` in any modern web browser.
3.  Navigate through the modules using the **NEXT** and **PREV** buttons.
4.  Complete the quiz to view your final awareness score.

## 🛠️ Technologies Used
* **HTML5** - Semantic structure.
* **CSS3** - Custom properties (variables), Flexbox, Keyframe animations, and Glassmorphism effects.
* **JavaScript (Vanilla)** - Navigation logic, progress tracking, and quiz engine.
